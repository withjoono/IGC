# IGC 이미지 가이드 (무료 스톡)

블로그·프로모 페이지에 넣을 사진을 **라이선스가 확실한 무료 스톡**으로 채우는 방법입니다.
(대학 브로슈어 사진은 저작권·허가 문제로 사용하지 않습니다.)

---

## 1. 쓸 수 있는 무료 스톡 & 라이선스

| 사이트 | 라이선스 요약 | 상업적 사용 | 출처표기 |
|---|---|---|---|
| **Unsplash** (unsplash.com) | Unsplash License | O | 불필요(권장) |
| **Pexels** (pexels.com) | Pexels License | O | 불필요(권장) |
| **Pixabay** (pixabay.com) | Pixabay Content License | O | 불필요 |

세 곳 모두 상업적 사용이 허용되고 출처표기 의무가 없습니다. 단 공통 제한이 있습니다.

- 사진을 **원본 그대로 재판매/재배포**하는 것은 금지(사이트에 쓰는 건 OK).
- **식별 가능한 인물·브랜드**가 특정 상품/서비스를 보증하는 것처럼 쓰면 안 됨.
- 다운로드 페이지에서 이미지별 라이선스를 한 번 더 확인(일부 스폰서/프리미엄 이미지는 조건이 다름).

## 2. 유료 컨설팅 사이트라서 특히 주의할 점

- **특정 실제 대학 건물·로고가 식별되는 사진은 피하세요.** "그 대학이 이 서비스를 보증한다"는 오해를 줄 수 있습니다. → 일반적인 캠퍼스·학습·글로벌·송도 도시 이미지 위주로.
- 인물 사진은 위 3개 스톡(모델 릴리스 확보분) 위주로.

## 4. 교체 방법 (아주 간단)

1. 위 사이트에서 이미지를 다운로드
2. `public/images/` 에 위 표의 파일명으로 저장
3. `src/data/igc.ts` 의 이미지 경로를 해당 파일명으로 변경

현재는 임시 플레이스홀더(`campus-1.svg`, `campus-2.svg`)를 가리키고 있습니다. 바꿀 부분:

```ts
// 블로그 "내신 5등급" 글
cover: "/images/blog-naesin.jpg",
figures: [
  { afterParagraph: 1, src: "/images/campus-songdo.jpg", caption: "인천글로벌캠퍼스 (사진: Unsplash)" },
],

// 블로그 "2027 마감일" 글
cover: "/images/blog-deadline.jpg",
```

## 7. 본교(홈 캠퍼스) 사진 — Wikimedia Commons (CC)

각 대학 상세 페이지(`/promo/universities/<id>`)에 **본교 캠퍼스 사진** 슬롯을 이미 붙여뒀습니다.
아래 파일 페이지에서 이미지를 내려받아 `public/images/`에 지정 파일명으로 저장하면 자동으로 표시됩니다(파일이 없으면 자동 숨김).

| 대학 | 저장 파일명 | Wikimedia Commons |
|---|---|---|
| 스토니브룩 | `uni-sbu.jpg` | https://commons.wikimedia.org/wiki/Category:Buildings_of_Stony_Brook_University |
| 조지메이슨 | `uni-gmu.jpg` | https://commons.wikimedia.org/wiki/File:GMU_Fairfax_Campus.JPG |
| 유타대 | `uni-utah.jpg` | https://commons.wikimedia.org/wiki/Category:University_of_Utah_buildings |
| 겐트대 | `uni-ghent.jpg` | https://commons.wikimedia.org/wiki/Category:Ghent_University |

**중요 — CC 라이선스는 출처표기가 필요합니다.** 대부분 CC BY-SA라서 저작자·라이선스를 밝혀야 합니다.
- 각 파일 페이지에서 **Author(저작자)** 와 **License(CC BY / CC BY-SA 등)** 를 확인하세요.
- 그 내용을 `src/data/photos.ts` 의 해당 대학 `credit` 에 기입하면, 사진 아래 캡션으로 노출됩니다.
- 예: `credit: "Stony Brook Union, © Photographer명, CC BY-SA 4.0 (Wikimedia Commons)"`
- `public/images/CREDITS.md` 표에도 같이 기록하세요.

> 팁: 로고·간판이 크게 박힌 컷보다 건물·캠퍼스 전경 컷이 "보증 오해" 위험이 적습니다.
